# АвтоТефтер — тестова версия за Android

Дневник за лек автомобил. Данните и снимките се пазят само на телефона, без акаунт, сървър и плащане.

## Какво може
- **Срокове:** ГТП (според възрастта на колата), гражданска (и вноските), каско, винетка, данък. Получавате известия на телефона 14 и 7 дни преди срока, дори когато приложението е затворено.
- **Масло и поддръжка:** масло с номерата на филтрите, скоростна кутия, ангренаж, антифриз, спирачна течност и др. с интервали.
- **Гориво:** снимате касовата бележка и километража. Приложението смята разхода на 100 км и предупреждава, ако се повиши.
- **Снимки:** талон (голям или малък), касови бележки, фактури, винетка, полица. Текстът се разчита **на самия телефон** (Google ML Kit, офлайн и безплатно) и полетата се попълват. Проверявайте ги, преди да запазите.
- **Продажба:** бутонът „Изпрати историята на купувача“ създава файл, който пращате по Viber, имейл и т.н. Купувачът го отваря с „Отвори файл с история“.
- **Резервно копие:** от настройките (зъбчатото колело) запазвате копие във файл и го възстановявате от файл.

## Как се получава APK (безплатно)
1. Качете тази папка в хранилище в GitHub (безплатен акаунт).
2. GitHub Actions компилира приложението автоматично (`.github/workflows/android.yml`). Отнема около 10 минути.
3. Свалете `AvtoTefter.apk` от раздела **Releases → latest** направо на телефона.
4. На телефона разрешете „Инсталиране от неизвестни източници“ за браузъра или файловия мениджър и отворете файла.

## Локално компилиране (по желание)
```
npm ci
npm run sync          # събира native.js и копира www/ в android/
cd android && ./gradlew assembleDebug
```
Нужни са JDK 21 и Android SDK.

## Структура
- `www/index.html` — цялото приложение (интерфейс и логика).
- `src/native.js` — връзка с камерата, файловете, известията, споделянето и разпознаването на текст. Събира се до `www/native.js`.
- `android/` — Android проектът (Capacitor 8).
